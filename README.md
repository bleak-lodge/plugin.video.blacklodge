# plugin.video.blacklodge
Blacklodge add-on

--- For testing and learning purposes - Not for public use (use at your own risk) ---

--- NOTE: The version on this git repo does not come with API keys                ---


This Kodi add-on fetches official stream urls/ids from various streaming services, and sends them to their equivalent Kodi add-on for playback.
NOTE: This add-on uses free and legal resources for its purposes. User has to have installed and configured (with linked active account where required) the supported services' equivalent add-ons in order to achieve playback.
